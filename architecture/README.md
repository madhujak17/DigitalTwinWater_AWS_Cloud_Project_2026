# Architecture Diagrams

This directory contains the visual architecture diagrams for the Digital Twin Cloud Framework:

1. `AWS_Cloud_Architecture.png`: Details the interaction between AWS IoT Core, Lambda, S3, RDS, SageMaker, EC2, CloudWatch, and SNS.
2. `Complete_System_Architecture.png`: Illustrates the end-to-end data flow from the physical EPANET simulation to the cloud ingestion pipeline and operator dashboard.
